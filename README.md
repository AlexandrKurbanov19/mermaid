# mermaid → схемы Нетологии

[![Deploy to GitHub Pages](https://github.com/AlexandrKurbanov19/mermaid/actions/workflows/deploy.yml/badge.svg)](https://github.com/AlexandrKurbanov19/mermaid/actions/workflows/deploy.yml)

Одностраничное React-приложение: вставляешь Mermaid-разметку слева — справа получаешь схему
в фирменном стиле Нетологии и кнопки «Скачать PNG / SVG».

**Демо:** https://alexandrkurbanov19.github.io/mermaid/

## Что умеет

- разбирает **`flowchart` / `graph`** (все формы + `subgraph`, бейджи-номера, шевроны) и **`timeline`** (ось, кружки, подписи сверху/снизу, секции) — переводит в собственный DSL и рисует своим SVG-рендерером;
- **пользователь не может менять стили**: `classDef`, `style`, `linkStyle`, `class`, `click`, `%%{init}%%` игнорируются (с предупреждением). Единственное, что влияет на вид узла — маркеры `:::accent` (брендовая заливка), `:::secondary` (синий акцент), `:::outline` (белая карточка с акцентной рамкой), `:::muted` (пунктирный «необязательный» блок). Номер в начале лейбла (`1. Понять проблему`) автоматически выносится в кружок-бейдж;
- **fit-text**: если текста в блоке много, блок не растягивается — уменьшается шрифт (до 11 px), в пределе ставится «…»;
- зум колесом, панорама перетаскиванием, двойной клик — «вписать в окно»;
- экспорт PNG (1×/2×/3×, опционально прозрачный фон) и SVG — со вшитым шрифтом SB Sans Text, чтобы картинка не «съезжала» на фолбэк;
- **справочник по синтаксису** прямо в приложении (кнопка «Синтаксис ?»): 31 рабочий сниппет по 7 группам, каждый можно вставить одним кликом. Сниппеты проверяются тестом — если справочник разойдётся с парсером, тест упадёт;
- 30 готовых кейсов в выпадающем списке ([docs/EXAMPLES.md](docs/EXAMPLES.md)).

Без роутинга, без стейт-менеджера, без сохранения состояния — только локальный стейт (`useState`).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5199
```

| Скрипт | Что делает |
|---|---|
| `npm run dev` | дев-сервер |
| `npm run build` | прод-сборка в `dist/` |
| `npm run preview` | локальный просмотр сборки |
| `npm test` | юнит-тесты (Vitest) |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run docs:examples` | перегенерировать `docs/EXAMPLES.md` из `src/examples.ts` |

## Деплой

Автоматически: пуш в `main` → `.github/workflows/deploy.yml` (typecheck → тесты → сборка → GitHub Pages).

Один раз нужно включить Pages: **Settings → Pages → Source: GitHub Actions**
(воркфлоу пытается включить сам через `enablement: true`, но для приватных репозиториев это требует прав администратора).

Сайт живёт в подпапке `/<repo>/`, поэтому при сборке передаётся `VITE_BASE`:

```bash
VITE_BASE=/mermaid/ npm run build   # локальная проверка «как на Pages»
```

## Структура

```
src/
  App.tsx                     # страница: textarea + предпросмотр + кнопки
  syntax.ts                   # справочник по синтаксису (проверяется тестом)
  components/SyntaxHelp.tsx   # панель справочника
  examples.ts                 # 24 кейса для проверки
  diagram/
    ir.ts                     # DiagramIR — наш DSL (v1), без цветов и координат
    parse/                    # mermaid -> IR: нормализация форм, рёбер, подписей
    measure/                  # метрики SB Sans Text, перенос строк, fit-text, габариты узлов
    layout/                   # ELK: слои, ортогональные рёбра, кластеры групп
    render/                   # SVG-рендерер, развод рёбер и подписи, зум/панорама
    export/                   # SVG-строка с base64-шрифтом, растеризация в PNG
    theme.ts                  # ЕДИНСТВЕННОЕ место с цветами/шрифтами/размерами
docs/
  PLAN.md                     # архитектура, план этапов, принятые решения
  AUDIT.md                    # аудит референсов: где архив противоречил сам себе
  THEME.md                    # точные токены: палитра, типографика, геометрия
  EXAMPLES.md                 # кейсы для копипаста
  COVERAGE.md                 # разбор архива: что из 25 слайдов воспроизводим
  SPEC-ITERATION-2.md         # спека итерации 2: таймлайн, бейджи, шеврон, синяя роль
```

## Ограничения (v1)

- только `flowchart`/`graph` и `timeline`; `sequenceDiagram`, `gantt` и прочие типы дают понятную ошибку;
- диаграммы из архива, которые не являются блок-схемами (пирамида, таймлайн, венн) не поддерживаются;
- бандл крупный (mermaid + ELK), при необходимости урезается до одного типа диаграмм.
