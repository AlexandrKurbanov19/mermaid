# Кейсы для проверки

Тот же список доступен в приложении — выпадающий список над редактором.
Копируй блок целиком и вставляй в textarea.

## 1. Пример из задачи

_Проверяет: база: бокс, ромб, подписи рёбер, цикл D → B_

```mermaid
graph TD
    A[Пользователь] --> B{Авторизован?}
    B -- да --> C[Открыть дашборд]
    B -- нет --> D[Показать логин]
    D --> B
```

## 2. Линейный процесс

_Проверяет: простая цепочка, вертикальная раскладка_

```mermaid
graph TD
    A[Заявка] --> B[Проверка] --> C[Согласование] --> D[Запуск] --> E[Отчёт]
```

## 3. Все формы

_Проверяет: box, round, pill, circle, hexagon, decision_

```mermaid
graph LR
    A[Прямоугольник] --> B(Скруглённый)
    B --> C([Капсула])
    C --> D((Круг))
    D --> E{{Шестиугольник}}
    E --> F{Ромб}
```

## 4. Экзотические формы

_Проверяет: все сводятся к обычному блоку + предупреждение_

```mermaid
graph TD
    A[[Подпрограмма]] --> B[(Цилиндр)]
    B --> C[/Параллелограмм/]
    C --> D[\Трапеция\]
    D --> E>Асимметрия]
```

## 5. Все типы связей

_Проверяет: solid, dashed, thick, без стрелки, двусторонняя_

```mermaid
graph TD
    A --> B
    B -.-> C
    C ==> D
    D --- E
    E <--> F
```

## 6. Подписи связей, два синтаксиса

_Проверяет: |текст| и -- текст -->_

```mermaid
graph TD
    A[Старт] -->|успех| B[Продолжить]
    A -- ошибка --> C[Повторить]
    B -->|готово| D[Конец]
    C --> A
```

## 7. Горизонтальная схема (LR)

_Проверяет: направление слева направо_

```mermaid
graph LR
    A[Идея] --> B[Исследование] --> C[Прототип] --> D[Запуск]
```

## 8. Снизу вверх (BT)

_Проверяет: обратное направление_

```mermaid
graph BT
    A[Факт] --> B[Вывод] --> C[Решение]
```

## 9. Текст: короткий (шрифт 18)

_Проверяет: базовый размер, минимальный бокс_

```mermaid
graph TD
    A[Ок] --> B[Да]
```

## 10. Текст: средний (перенос строк)

_Проверяет: обёртка в 3 строки, шрифт ещё базовый_

```mermaid
graph TD
    A[Пользователь авторизован и открывает дашборд] --> B[Готово]
```

## 11. Текст: длинный (шрифт уменьшается)

_Проверяет: fit-text: бокс НЕ растёт, шрифт падает до ~13px_

```mermaid
graph TD
    A[Очень длинный текст в одном блоке, который описывает сразу несколько шагов сценария и никак не хочет помещаться в стандартный прямоугольник схемы] --> B[Короткий]
```

## 12. Текст: огромный (обрезка «…»)

_Проверяет: предел: шрифт 11px, многоточие, бокс не выходит за 260×132_

```mermaid
graph TD
    A[Очень длинный текст в одном блоке. Очень длинный текст в одном блоке. Очень длинный текст в одном блоке. Очень длинный текст в одном блоке. Очень длинный текст в одном блоке. Очень длинный текст в одном блоке. Очень длинный текст в одном блоке. Очень длинный текст в одном блоке.] --> B[Короткий]
```

## 13. Текст: одно слово без пробелов

_Проверяет: жёсткий перенос по символам_

```mermaid
graph TD
    A[суперкалифраджилистикэкспиалидоция] --> B[Ок]
```

## 14. Markdown в подписях

_Проверяет: **жирный**, `код`, <br/> перенос_

```mermaid
graph TD
    A["**Шаг 1**<br/>модель извлекает `json`"] --> B["Шаг 2<br/>сервис находит **заказ**"]
```

## 15. Акцентный узел

_Проверяет: :::accent даёт брендовую заливку_

```mermaid
graph TD
    A[Обычный шаг] --> B[Важный шаг]:::accent
    B --> C[Финал]
```

## 16. Пользовательские стили (игнорируются)

_Проверяет: classDef/style не применяются, показывается предупреждение_

```mermaid
graph TD
    A[Первый] --> B[Второй]
    classDef red fill:#ff0000,stroke:#000
    class A red
    style B fill:#00ff00
```

## 17. Группа (subgraph)

_Проверяет: группы рисуются пунктирными контейнерами (ELK-кластеры)_

```mermaid
graph TD
    subgraph Стадион
      A[Бригады] --> B[Клубы]
    end
    subgraph Студия
      C[Режиссёр] --> D[Support]
    end
    B --> C
```

## 18. Много узлов (20)

_Проверяет: производительность и читаемость большой схемы_

```mermaid
graph TD
    N1 --> N2 --> N3 --> N4 --> N5
    N1 --> N6 --> N7 --> N8
    N3 --> N9 --> N10
    N5 --> N11 --> N12
    N7 --> N13 --> N14
    N9 --> N15
    N11 --> N16 --> N17
    N13 --> N18 --> N19 --> N20
```

## 19. Веер: 1 → 6 и 6 → 1

_Проверяет: широкая раскладка, много параллельных линий_

```mermaid
graph TD
    A[Центр] --> B1[Раз]
    A --> B2[Два]
    A --> B3[Три]
    A --> B4[Четыре]
    A --> B5[Пять]
    A --> B6[Шесть]
    B1 --> C[Сбор]
    B2 --> C
    B3 --> C
    B4 --> C
    B5 --> C
    B6 --> C
```

## 20. Несвязные компоненты

_Проверяет: два независимых графа на одном холсте_

```mermaid
graph TD
    A[Один] --> B[Два]
    C[Три] --> D[Четыре]
```

## 21. Петля на себя

_Проверяет: ребро A → A не должно ломать раскладку_

```mermaid
graph TD
    A[Старт] --> A
    A --> B[Финал]
```

## 22. Ромб с длинным текстом

_Проверяет: текст вписан в 0.60×0.50 ромба, не вылезает за скосы_

```mermaid
graph TD
    A{Пользователь авторизован и имеет активную подписку?} --> B[Да]
    A --> C[Нет]
```

## 23. ОШИБКА: битый синтаксис

_Проверяет: плашка ошибки, превью не падает_

```mermaid
graph TD
    A[Старт] -->
    B -->--> C
```

## 24. ОШИБКА: другой тип диаграммы

_Проверяет: sequenceDiagram в v1 не поддерживается_

```mermaid
sequenceDiagram
    A->>B: привет
```
