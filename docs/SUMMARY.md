# Mermaid → схемы Нетологии: сводка по проекту

**Одной строкой:** одностраничное React-приложение, которое превращает Mermaid-разметку в схему в фирменном стиле Нетологии и скачивает её картинкой (PNG/SVG).

---

## Зачем это нужно

В Нетологии много схем в маркетинговых и учебных материалах (есть архив из 25 слайдов-референсов). Их рисуют руками в разных редакторах, поэтому в одном архиве встречаются **4 разных зелёных, 3 серых, два типа стрелок** и т.д.

Цель — инструмент «вставил текст → получил картинку» в **едином брендовом стиле**, чтобы убрать «человеческий фактор» и не звать дизайнера на каждую схему.

## Что умеет (функционал)

- Слева textarea с Mermaid, справа живой предпросмотр, кнопки **«Скачать PNG»** (1×/2×/3×, прозрачный фон) и **«Скачать SVG»**.
- **9 типов диаграмм**: flowchart, state, sequence, class, ER, mindmap, journey, gantt, timeline.
- Пользователь **не может менять стили**: `classDef`/`style`/`linkStyle` игнорируются с предупреждением. Вид меняют только предопределённые маркеры `:::accent`/`:::secondary`/`:::outline`/`:::muted` и бейджи-номера (`1. Понять проблему`).
- **Fit-text**: если текста в блоке много — блок не растягивается, шрифт уменьшается (до 11 px, дальше «…»).
- Зум колесом, панорама перетаскиванием, «вписать в окно»; мобильная раскладка («башенка»).
- Встроенный **справочник синтаксиса** (31 сниппет, вставка в один клик) + 37 готовых кейсов.
- Экспорт со **вшитым шрифтом SB Sans Text** (base64), чтобы картинка не «съезжала» на фолбэк.

## Как устроено (архитектура)

```
Mermaid → парсер (mermaid db) → свой DSL (DiagramIR, JSON) → нормализация → раскладка → свой SVG-рендер → экспорт
```

- **Свой DSL** (`DiagramIR`, версия v1) — промежуточный JSON без цветов и координат: рендерер не знает, что такое Mermaid.
- Нормализация задаёт **правила** (13 фигур → 8 ролей, стили юзера выбрасываются) — это и есть «стандартизация».
- Раскладка: **ELK** (ортогональные рёбра как в архиве) для графов, свои алгоритмы для sequence/gantt/mindmap/timeline/journey.
- Вся тема — в одном файле `theme.ts` (палитра, шрифты, отступы, геометрия).
- **Без стейт-менеджера, без памяти, без бэкенда** — только локальный `useState`.

## Дизайн (стиль Нетологии)

- Палитра из `vars.sass` продукта: брендовый зелёный `#4BD0A0`, заливка `#F3F4F7`, радиус 12, текст `#27292D`.
- Шрифт **SB Sans Text** (гарнитура DS Сбера, та же, что в лендингах).
- Ортогональные стрелки с прямыми углами — как в доминирующем семействе архива.
- Контраст посчитан (белый на мяте — 1.80:1 → в акцентах тёмный текст).
